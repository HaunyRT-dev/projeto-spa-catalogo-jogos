# 🎮 Meu Catálogo de Jogos

Projeto prático para estudos. Página web onde é possível cadastrar meus jogos, montar uma lista com os favoritos e ver estatísticas da coleção. 

Tudo funciona em uma única tela, sem precisar recarregar a página.

## 🕹️ O que o site faz
* **Adicionar jogos:** Posso salvar o nome, a plataforma e o gênero de cada jogo.
* **Favoritar:** Dá para marcar os jogos que eu mais gosto com uma estrelinha.
* **Excluir:** Posso apagar um jogo da lista.
* **Gráfico:** Gráfico automático mostrando proporção de de estilos de jogo mais cadastrados e consoles mais usados.

## 🛠️ O que eu usei para criar
* **HTML e CSS:** Para montar a estrutura da tela, fazer os botões e deixar o visual com um tema escuro.
* **JavaScript:** Para dar vida à página (fazer os botões funcionarem, salvar os jogos na memória e atualizar a tela na hora).
* **Chart.js:** Uma ferramenta externa que usei apenas para desenhar o gráfico colorido.
